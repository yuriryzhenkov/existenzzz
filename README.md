# EXISTENZZZ

Общее грибное пространство в браузере. Ходишь на WASD как в CS, рисуешь на стенах (стирать нельзя),
слушаешь генеративную музыку, которая слышит, сколько людей рядом.

- Играть: https://yuriryzhenkov.github.io/existenzzz/
- Сервер: https://existenzzz.yuriryzhenkov.workers.dev (Cloudflare Worker + Durable Object + SQLite)

Подробности — в [docs/HANDOFF.md](docs/HANDOFF.md).
